# SOBEK Khal Network Updater

Repository: https://github.com/arafatkabirrony/sobek-khal-network-updater

A Python GUI tool to process BTM-projected Khal shapefiles, generate connection and boundary nodes, preview schematisation visually with mouse scroll zoom and node selection, and merge updated reaches into existing SOBEK `network.ntw` files.

Developed by Arafat Kabir

## Local Run (Windows)
1. Install dependencies (`geopandas`, `shapely`, `matplotlib`, `pandas`) in your conda environment.
2. Update `CONDA_ENV` inside `run_updater.bat` if needed.
3. Double-click `run_updater.bat`.
